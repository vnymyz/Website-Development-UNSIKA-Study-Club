# Panduan Proyek Akhir — Aplikasi Web CRUD

Proyek dikerjakan **setelah sesi 6** dalam kelompok berisi **3–4 orang**. Detail tenggat dan ada/tidaknya presentasi akan diumumkan kemudian.

## Tujuan

Buat aplikasi web yang menyimpan dan mengelola data nyata memakai database, bukan sekadar halaman statis. Proyek ini bukan hanya tugas kelas — hasil akhirnya diharapkan cukup layak untuk dipajang sebagai portofolio kerja saat melamar kerja atau magang.

## Ketentuan minimum

1. Pilih studi kasus dengan data yang jelas entitasnya (boleh melanjutkan tema UMKM dari kelas, atau topik lain yang disetujui).
2. Minimal **dua tabel database yang saling berelasi** (misalnya tabel utama dan tabel kategori).
3. Fitur **CRUD penuh**: tambah data, lihat data, ubah data, hapus data.
4. Sistem **login dan register** memakai Supabase Auth; halaman/aksi tertentu hanya bisa diakses setelah login.
5. Tampilan **responsif** — enak dilihat di HP maupun laptop.
6. Aplikasi **ter-deploy** dan bisa dibuka lewat URL publik (Vercel).
7. Simpan kode dalam repository GitHub; setiap anggota melakukan minimal beberapa kontribusi yang terdokumentasi lewat commit.
8. Sediakan `README.md`: anggota kelompok, deskripsi aplikasi, fitur, tech stack, cara menjalankan secara lokal, dan tautan demo.

## Ide topik cadangan

- Katalog dan direktori UMKM (melanjutkan studi kasus kelas).
- Sistem peminjaman ruang atau alat kampus/himpunan.
- Pendaftaran dan manajemen event kampus/organisasi.
- Katalog perpustakaan mini atau peminjaman buku.
- Tracker tugas kelompok/organisasi dengan status pengerjaan.

## Pengumpulan dan presentasi

Pengumpulan dapat menggunakan tautan repository GitHub dan/atau URL deploy Vercel sesuai arahan penyelenggara. Bila ada presentasi, setiap kelompok menyiapkan demo aplikasi langsung dan penjelasan singkat: masalah yang diselesaikan, struktur database, fitur utama, dan pembagian kerja tim.
