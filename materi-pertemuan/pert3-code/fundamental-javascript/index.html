Latihan Fundamental JavaScript

Satu section = satu konsep. Buka Inspect (F12) > Console sebelum mulai — sebagian besar hasilnya muncul di sana, bukan cuma di halaman. Coba ganti-ganti nilai di tiap file .js, simpan, lalu refresh buat lihat efeknya sendiri.

1. Variabel & Tipe Data — var.js

let vs const, dan empat tipe data dasar.

2. Kondisi (if/else) — condition.js

Cek stok barang: kalau lebih dari 0, tersedia; kalau tidak, habis.

3. Perulangan (for) — loop.js

Mencetak angka 1 sampai 5 tanpa menulis console.log lima kali.

4. Function — function.js

formatRupiah(angka): menerima angka, mengembalikan teks berformat.

5. Array & Object — arrayobject.js

Array of object: beberapa produk, tiap produk punya nama dan harga.

6. Console Log — consolelog.js

Bagian ini tidak nulis apa-apa ke halaman — semua hasilnya cuma muncul di tab Console. Buka Console sekarang buat lihat.

7. Input & Output — inputoutput.js

Ketik nama, klik tombol, lihat hasilnya ditulis ke halaman.

8. DOM — dom.js

querySelector, .textContent, dan .style dipakai buat ubah teks dan warna paragraf di bawah ini — otomatis begitu halaman dimuat, tanpa diklik.

Teks ini akan diubah oleh dom.js

9. Event — event.js

addEventListener("click", ...) — klik tombolnya.
