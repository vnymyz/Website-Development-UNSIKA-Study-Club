Struktur Dasar

Susunan Tag Semantik

Tiap tag punya tempatnya sendiri. Perhatikan urutan munculnya kotak di bawah — itu urutan tag ditulis di HTML.

<header>
Logo + menu navigasi
<main>
<section> Daftar UMKM
<footer> Hak cipta
📌 Dipakai buat apa di website asli?
  • <header> — bagian paling atas halaman: logo, nama website, menu navigasi. Biasanya cuma 1 per halaman dan selalu muncul di posisi sama di tiap halaman.
  • <main> — konten utama yang jadi alasan orang buka halaman ini (isi artikel, daftar produk, dsb). Cuma boleh ada 1 per halaman.
  • <section> — mengelompokkan konten yang temanya sama dan biasanya punya judul sendiri (misal: "Daftar UMKM", "Tentang Kami"). Boleh banyak dalam 1 halaman.
  • <footer> — bagian paling bawah: hak cipta, alamat, link sosial media, kontak.
Kotak Generik

<div> vs <span>

div ambil satu baris penuh (block). span cuma sebesar isinya, nempel di tengah kalimat (inline).

Ini isi sebuah <div> — perhatikan lebarnya penuh satu baris.

Status warung: Buka sampai jam 9 malam.

📌 Dipakai buat apa di website asli?
  • <div> — pembungkus umum buat sekelompok elemen supaya bisa di-styling/ditata bareng. Contoh nyata: kartu produk (bungkus gambar+judul+harga jadi satu blok), wrapper untuk Flexbox/Grid, container buat batasi lebar konten.
  • <span> — buat menandai sebagian kecil teks di tengah kalimat/paragraf. Contoh nyata: badge kecil ("Baru!", "Diskon"), kata yang diberi warna beda, ikon kecil yang nempel di sebelah teks.
  • Bedanya: div block (ambil satu baris penuh, buat bungkus blok konten), span inline (cuma sebesar isinya, buat sorot sebagian teks). Keduanya tidak punya makna semantik — dipakai kalau memang tidak ada tag semantik yang cocok.

Box Model

Klik salah satu tombol untuk menyorot lapisan itu di kotak sebelah kanan.

Isi
📌 Pengertian tiap lapisan
  • Content — isi asli elemen (teks, gambar). Ini yang pertama ditulis, sisanya "bungkus" di sekelilingnya.
  • Padding — jarak di dalam, antara isi dan garis border. Dipakai supaya teks/isi tidak mepet ke pinggir — contoh: tombol tanpa padding kelihatan sempit dan teksnya nempel ke tepi.
  • Border — garis pembatas visual di sekeliling elemen. Dipakai buat kartu produk (garis tipis abu-abu), pembatas antar section, atau garis warna saat elemen di-fokus.
  • Margin — jarak di luar, antara elemen ini dan elemen tetangganya. Dipakai supaya kartu-kartu produk tidak saling mepet, atau paragraf punya jarak dari judul di atasnya.

Display: block / inline / inline-block

Klik tombolnya, lihat 3 kotak di bawah berubah susunannya secara live.

Kotak 1
Kotak 2
Kotak 3
📌 Dipakai buat apa di website asli?
  • block — elemen yang harus berdiri sendiri satu baris: paragraf, section, div, heading. Default-nya sebagian besar elemen "besar".
  • inline — elemen kecil yang nempel di tengah kalimat: span, a, strong. Tidak bisa diatur lebar/tinggi/margin atas-bawah.
  • inline-block — paling sering dipakai untuk menu navigasi (link-link sejajar horizontal tapi masing-masing bisa diberi padding/lebar) dan badge/tombol kecil yang harus sejajar tapi tetap punya ukuran presisi.
Fondasi CSS

Position: static / relative / absolute

Kotak kuning akan berpindah sesuai tombol yang dipilih. Kotak putih di pojok kiri-atas adalah "parent" referensinya.

parent (relative)
saya
📌 Dipakai buat apa di website asli?
  • static — default, ikut alur normal dokumen. Dipakai kalau memang tidak butuh geser-geser posisi.
  • relative — dipakai kalau elemen mau digeser sedikit dari posisi normalnya, atau (lebih sering) dipakai di elemen parent supaya jadi acuan buat anaknya yang absolute.
  • absolute — dipakai buat badge notifikasi di pojok ikon, tombol close (x) di pojok modal/popup, watermark di pojok gambar — semua yang harus "nempel presisi" di satu titik dan tidak ikut mendorong elemen lain.
  • fixed / sticky — dipakai buat navbar yang tetap kelihatan saat halaman di-scroll ke bawah (sangat umum di website nyata).

📌 Dipakai buat apa di website asli?
  • Menyusun kartu-kartu produk/UMKM sejajar horizontal dan otomatis pindah baris kalau layar sempit (flex-wrap).
  • Menyusun menu navigasi di header supaya logo di kiri dan link-link di kanan (justify-content: space-between).
  • Menengahkan konten secara vertikal+horizontal tanpa trik ribet (align-items: center; justify-content: center;) — ini pola paling sering dicari pemula CSS.
  • Menyusun footer jadi beberapa kolom (kontak, sosial media, peta situs) yang sejajar.
Interaksi Tanpa JS

Pseudo-class :hover

Arahkan kursor (jangan diklik) ke kartu dan tombol di bawah ini.

Arahkan kursor ke sini
📌 Dipakai buat apa di website asli?
  • Tombol berubah warna/naik dikit saat disorot — kasih sinyal "ini bisa diklik" tanpa perlu JavaScript sama sekali.
  • Link navigasi dapat garis bawah/warna beda saat disorot — memudahkan orientasi pengguna sedang arahkan kursor ke mana.
  • Kartu produk sedikit membesar/mengangkat bayangan saat disorot — efek ini yang bikin toko online kelihatan "hidup" dan responsif terhadap interaksi pengguna.
